# 作業整體流程

這份作業的目標是：**用 Kubernetes（Minikube）部署一個自訂 Nginx 映像的靜態網頁，並從瀏覽器存取**。
本版整合了 Docker / Containerd / Git / GitLab CI 四項技術。

---

```
┌─────────────────────────────────────────────────────────────────┐
```

## GitLab CI/CD 自動化路徑

```
開發者 commit / push 到 main
            ↓
┌────────────────────────────────────────────────────────────────┐
│                 GitLab CI/CD Pipeline                          │
│                                                                │
│  ① build:  docker build → image artifact                       │
│            ↓                                                   │
│  ② test:   kubectl --dry-run 驗證 YAML                          │
│            Trivy 掃描映像 CVE 漏洞                              │
│            ↓                                                   │
│  ③ push:   docker login → docker push                          │
│            registry.gitlab.com/<group>/<project>:<SHA>         │
│            ↓                                                   │
│  ④ deploy: kubectl set image deployment/nginx-deployment       │
│            kubectl rollout status（等待新版 Pod 就緒）          │
│            （manual trigger，正式環境需人工確認）                │
└────────────────────────────────────────────────────────────────┘
            ↓
       K8s 叢集滾動更新
            ↓
       新版映像服務上線
```

## 流程步驟說明

| 步驟 | 動作 | 技術 |
|------|------|------|
| **①** | 開啟 Docker Desktop | Docker |
| **②** | `minikube start --driver=docker --container-runtime=containerd` | Minikube + Containerd |
| **③** | `minikube image build -t syswatch-nginx:1.0.0 .` | Docker (Dockerfile) |
| **④** | `kubectl apply -f deployment.yaml / service.yaml` | Kubernetes |
| **⑤** | `minikube service nginx-service --url` | Minikube |
| **⑥** | 瀏覽器開啟網址 | — |

---

## 流量走向（從瀏覽器到網頁）

```
瀏覽器
   │
   │ http://192.168.49.2:30080
   ▼
Service (NodePort 30080)
   │
   │ 轉發到 Pod port 80
   ▼
Pod (Nginx 容器，由 Containerd 執行)
   │
   │ 讀取 /usr/share/nginx/html/index.html
   │ （HTML 已於 docker build 時 COPY 進映像）
   ▼
回傳 HTML 給瀏覽器 → 顯示網頁
```

## 專案檔案的分工

| 檔案 | 任務 | 技術 |
|------|------|------|
| `Dockerfile` | 定義「如何打包應用程式為映像」 | Docker |
| `html/index.html` | 應用程式內容（靜態網頁） | — |
| `deployment.yaml` | 定義「要跑什麼」：Pod 規格、資源限制、探針 | Kubernetes |
| `service.yaml` | 定義「怎麼連進去」：對外開放 port 30080 | Kubernetes |
| `.gitlab-ci.yml` | 定義「如何自動 build → test → push → deploy」 | GitLab CI |
| `.gitignore` | 排除不應入版控的檔案（bin/、*.exe、kubeconfig）| Git |
| `deploy.ps1` | 本機自動化腳本：一鍵執行 ②③④⑤ | PowerShell |

---

## 第一次 vs 之後每次（本機開發）

**第一次（含初始化）**：步驟 ① → ② → ③ → ④ → ⑤ → ⑥

**修改 HTML 後**：步驟 ③ → `kubectl rollout restart deployment/nginx-deployment` → ⑤ → ⑥
（需重 build 映像並觸發 rollout，K8s 才會載入新版）

**只重啟環境**：步驟 ① → ② → ⑤ → ⑥
（叢集會記得 Deployment/Service，不需重新 apply）
